# Kiln 2.0.0-alpha.1

!!! note "Pre-release"
    This is documentation for an unreleased, pre-release version of Kiln. APIs
    here may change before the final release.

This version is a minimal example of how Kiln renders a **pre-release** alongside
the latest stable docs:

- it lives under `/2.0.0-alpha.1/` while the latest docs stay at the site root,
- the version switcher marks it as a pre-release,
- like all non-default versions it's `noindex` and self-canonical, so it won't
  compete with the stable docs in search.

Use the version switcher in the header to return to the latest stable docs.
