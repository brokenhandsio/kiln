# Kiln 0.9

!!! warning "Older version"
    You're viewing the documentation for an older version of Kiln. This page is
    a minimal example of how Kiln renders a previous version alongside the
    latest one.

This version exists only to demonstrate Kiln's **documentation versioning**:

- it lives under `/0.9/` while the latest docs stay at the site root,
- the **version switcher** in the header jumps between versions (always landing
  on each version's home page),
- older versions are marked `noindex` and self-canonical so they don't compete
  with the latest docs in search.

Use the version switcher to return to **Latest** for the real documentation.
